# Фронтенд-приложение: Каталог и Лента камер видеонаблюдения (ЛР5)

## 1. Общие сведения
- **Дисциплина**: Проектирование систем и продуктовая веб-разработка (РИП).
- **Модуль**: 2.
- **Лабораторная работа №5**: Разработка базового SPA на React (гостевой режим, работа на моках).
- **Студент**: Чоботов Л.К., группа ИУ5-51Б.
- **Тема 9**: Расчет энергопотребления системы видеонаблюдения.
  - Услуги: модели камер (`cameras`).
  - Поля по теме: мощность (`power`, Вт), разрешение (`resolution`), тип корпуса (`is_outdoor`, `housing_type`).
  - Фильтрация: по мощности (`power`).

---

## 2. Стек технологий и архитектура
- **Фреймворк**: React 18
- **Язык программирования**: TypeScript (строгая типизация)
- **Сборщик**: Vite 5
- **UI-библиотека**: React-Bootstrap 2 + Bootstrap 5
- **Маршрутизация**: React Router DOM 6
- **Управление состоянием**: локальное состояние на React Hooks (`useState`, `useEffect`, `useParams`, `useNavigate`) и `props`.
- **Ограничения лектора (А.И. Канев)**:
  - Никакого Redux в ЛР5 (будет в ЛР6).
  - Никакого React Context на всем курсе.
  - Никакого подключения к бэкенду, БД и S3 в ЛР5 (работа строго на мок-объектах).
  - Мобильный вертикальный фрейм 390px по центру экрана.

---

## 3. Описание страниц приложения

### 3.1. Страница «Плитка» (`CameraCatalogPage`, маршрут `/` или `/catalog`)
Страница предназначена для просмотра каталога опубликованных моделей камер в виде двухколоночной плитки.

**Элементы страницы**:
1. **Заголовок**:
   - «Каталог моделей камер» (Open Sans, bold 16px).
   - Подзаголовок «Тема 9: Расчет энергопотребления».
2. **Блок фильтрации по мощности (`PowerFilter`)**:
   - Ползунок (range-слайдер) со значениями от 3.0 Вт до 15.0 Вт.
   - Динамическое текстовое отображение порога «Мощность до: **X.X Вт**» (красный акцент `#D71820`).
   - Кнопка «Сбросить» для мгновенного сброса фильтра на максимальное значение (15.0 Вт).
   - Используемый хук: `useState<number>(15.0)`. При изменении слайдера список мгновенно пересчитывается без перезагрузки страницы.
3. **Двухколоночная сетка карточек (`Row` / `Col xs={6}`)**:
   - Карточки `CameraCard` шириной до 172px в белом блоке со скруглением 12px и серой рамкой `#EAEAEA`.
   - В каждой карточке:
     - Фотография камеры (с автоматическим фоллбэком на `/DefaultImage.jpg` при ошибке или пустом URL).
     - Название модели камеры (`model_name`, 13px bold).
     - Потребляемая мощность (`power`, красный цвет `#D71820`, 13px bold).
     - Разрешение матрицы (`resolution`, 11px semibold).
     - Бейдж типа корпуса (серый фон `#EAEAEA`: «Купольный», «Цилиндрический», «Корпусный»).
     - Счетчик лайков с красной иконкой сердечка.
4. **Переход на детальный экран («Лента»)**:
   - Клик по любой карточке вызывает `navigate('/feed/' + camera.id)`, открывая детальный полноэкранный просмотр соответствующей камеры в Ленте.

---

### 3.2. Страница «Лента» (`CameraFeedPage`, маршрут `/feed` или `/feed/:id`)
Страница детального просмотра камеры в формате вертикальной полноэкранной ленты (по аналогии с Reels / TikTok / Vibes).

**Элементы страницы**:
1. **Медиа-плеер (`<video>` / `<img>`)**:
   - Воспроизводит вертикальное видео камеры в цикле (`autoPlay loop muted playsInline`).
   - Если видеофайл не указан или произошла ошибка загрузки (`onError`), плеер автоматически переключается на изображение камеры либо дефолтное видео `/DefaultVideo.mp4`.
2. **Правая панель действий и параметров (`.feed-side-actions`)**:
   - **Кнопка «Следующий» / «Далее»**: крупная полукруглая кнопка 50×50px с радиусом скругления 22px, заливкой `#D71820` и белой стрелкой вправо. При клике вызывает функцию `getNextCameraId(currentId)` и циклически переключает ленту на следующую камеру.
   - **Бейдж мощности**: белая плашка со скруглением 20px, содержит значение мощности камеры (например, `3.6 Вт`, `6.0 Вт`).
   - **Бейдж разрешения**: белая плашка с разрешением матрицы (`Full HD`, `2K QHD`, `Super HD`).
   - **Кнопка лайка**: интерактивная иконка сердечка с числом лайков. При клике переключается между белым контуром и красной заливкой, динамически обновляя счетчик лайков через `useState`.
3. **Нижний информационный блок (`.feed-bottom-info`)**:
   - Название модели камеры (белый текст, 15px bold).
   - Описание камеры со спойлером: по умолчанию свернуто до 2 строк, кнопка «Ещё» разворачивает полное техническое описание камеры, после чего меняется на «Свернуть».
4. **Используемые хуки**:
   - `useParams<{ id: string }>()` — считывание ID выбранной камеры из URL.
   - `useNavigate()` — переход к следующей камере при клике «Следующий».
   - `useState` — управление разворачиванием описания (`expandedDesc`), состоянием лайка (`isLiked`), ошибкой видео (`videoError`).
   - `useEffect` — сброс состояний оверлеев при переключении `currentId`.

### 3.3. Нижняя панель навигации (`BottomNavBar`)
Фиксированная панель навигации высотой 70px внизу экрана с темным фоном `#2B2B2B`.

**Пункты меню (ровно 4 пункта)**:
1. **`Лента`** — **доступна** (активна, подсвечивается красным `#D71820` при нахождении на `/feed`, переходит на `/feed/1`).
2. **`Добавление`** — **недоступна** (заблокирована, `disabled`, пониженная прозрачность 0.35, бейдж «СКОРО»).
3. **`Плитка`** — **доступна** (активна, подсвечивается красным `#D71820` при нахождении на `/`, переходит в каталог).
4. **`Войти`** — **недоступна** (заблокирована, `disabled`, пониженная прозрачность 0.35, бейдж «СКОРО»).
