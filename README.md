# Фронтенд-приложение: Каталог и Лента камер видеонаблюдения (ЛР5)

## 1. Общие сведения
- **Дисциплина**: Проектирование систем и продуктовая веб-разработка (РИП).
- **Модуль**: 2.
- **Лабораторная работа №5**: Разработка базового SPA на React (гостевой режим, работа строго на моках, без подключения бэкенда, БД и S3).
- **Студент**: Чоботов Л.К., группа ИУ5-51Б.
- **Репозиторий фронтенда**: данный каталог `app/` полностью автономен и подготовлен как отдельный фронтенд-репозиторий для дальнейшего развития (ЛР6–ЛР7).
- **Тема 9**: Расчет энергопотребления системы видеонаблюдения.
  - Услуги (`cameras`): модели камер видеонаблюдения.
  - Поля сущности: `model_name`, `power` (Вт), `resolution`, `is_outdoor`, `housing_type`, `description`, `image_url`, `video_url`, `likes_count`, `status`.
  - Фильтрация каталога: по максимальной потребляемой мощности (`power`).

---

## 2. Стек технологий и архитектура
- **Фреймворк**: React 18
- **Язык программирования**: TypeScript (строгая типизация)
- **Сборщик**: Vite 5
- **UI-библиотека**: React-Bootstrap 2 (`Card`, `Form`, `Button`, `Nav`, `Badge`) + Bootstrap 5
- **Маршрутизация**: React Router DOM v6 (`BrowserRouter`, `Routes`, `Route`)
- **Управление состоянием**: локальное состояние компонентов на React Hooks (`useState`, `useEffect`, `useParams`, `useNavigate`, `useSearchParams`) и передача данных через `props`.
- **Ограничения лектора (А.И. Канев)**:
  - Запрещён Redux в ЛР5 (внедряется в ЛР6).
  - Запрещён React Context на всём курсе.
  - Запрещено подключение к бэкенду, БД и S3/MinIO в ЛР5 (работа строго на локальной mock-коллекции).
  - Фиксированный мобильный фрейм шириной `390px`, центрированный на экране (`margin: 0 auto; max-width: 390px`), без адаптивных брейкпоинтов.
  - В ЛР5 доступны строго 2 страницы («Плитка» и «Лента»); в нижней панели навигации строго 4 пункта (2 активны, 2 заблокированы).

## 3. Описание всех 4 страниц и элементов интерфейса

### 3.1. Страница 1 — «Плитка» (`CameraCatalogPage`, маршруты `/` и `/catalog`) — **ДОСТУПНА**
Страница просмотра каталога опубликованных моделей камер в двухколоночной сетке.

**Элементы, поля и кнопки**:
1. **Заголовок страницы**: «Каталог камер».
2. **Форма фильтрации по мощности (`PowerFilter`)**:
   - Подпись-индикатор: `Мощность до: X.X Вт` (`Form.Label`).
   - Поле ввода (ползунок `Form.Control type="range"`, `id="power_max"`): диапазон `0.0` – `15.0` Вт, шаг `0.1` Вт. Обновляет временное состояние ползунка (`sliderPower` через `useState`).
   - Кнопка **«Найти»** (`Button type="submit"`): обрабатывает событие `onSubmit` формы, применяет выбранное пороговое значение (`appliedPower`), фильтрует массив камер через `getPublishedCameras(appliedPower)` и синхронизирует URL-параметр `?power=`.
   - Кнопка **«Сбросить фильтр»** (отображается в пустом состоянии при отсутствии подходящих камер): сбрасывает порог к `15.0` Вт и очищает локальный список удалённых карточек.
3. **Двухколоночная сетка карточек (`CameraCard`, компоненты `Card`, `Card.Img`, `Card.Title`, `Button`)**:
   - Изображение модели камеры (`image_url`) с автоматическим фоллбэком на `/DefaultImage.jpg` при пустом значении или ошибке загрузки (`onError`).
   - Название модели (`model_name`), мощность (`power`, Вт), разрешение (`resolution`), счетчик лайков (`likes_count` с иконкой сердца).
   - Кнопка **«Удалить»** (`Button`): локально скрывает карточку в текущем сеансе (через `deletedIds` в `useState`, с `e.stopPropagation()`).
   - Клик по области карточки вызывает `navigate('/feed/' + camera.id)` и открывает страницу «Лента» на выбранной камере.

### 3.2. Страница 2 — «Лента» (`CameraFeedPage`, маршруты `/feed` и `/feed/:id`) — **ДОСТУПНА**
Страница полноэкранного вертикального просмотра модели камеры с видеодемонстрацией.

**Элементы, поля и кнопки**:
1. **Медиа-плеер (`<video>` / `<img>`)**:
   - Циклически воспроизводит видеоролик камеры (`video_url`) или подставляет `/DefaultVideo.mp4` при пустом поле. При ошибке воспроизведения (`onError`) переключается на фото камеры с фоллбэком на `/DefaultImage.jpg`.
2. **Правая панель действий (`.feed-side-actions`)**:
   - **Кнопка лайка** (иконка сердца + счётчик): локально переключает отметку лайка (`isLiked` в `useState`), окрашивает сердце в `#D71820` и меняет счётчик на `±1`.
   - **Круглая красная кнопка «Следующий»** (`Button`, цвет `#D71820` со стрелкой вправо): вызывает `getNextCameraId(currentId)` и переключает маршрут на следующую опубликованную камеру в каталоге.
   - **Бейджи параметров (`Badge`)**: отображают потребляемую мощность (`X.X Вт`) и разрешение (`Full HD` / `2K QHD` / `Super HD`).
3. **Нижний информационный блок (`.feed-info-block`)**:
   - Заголовок модели камеры (`model_name`).
   - Краткое/полное техническое описание (`description`) и кнопка **«Ещё» / «Свернуть»** (`Button`), управляемая состоянием `expandedDesc` (`useState`).

### 3.3. Страница 3 — «Добавление» (`Добавление камеры`, заблокирована в ЛР5) — **НЕДОСТУПНА**
Пункт меню **«Добавление»** в `BottomNavBar` присутствует, но помечен `disabled` и визуально приглушён (`opacity: 0.45`), переход на страницу создания камеры отключён по требованиям ЛР5 (гостевой режим на моках). В ЛР6–ЛР7 форма будет включать поля `Модель камеры` (`model_name`), `Потребляемая мощность (Вт)` (`power`), `Разрешение` (`resolution`), флаг `Уличная` (`is_outdoor`), `Описание` (`description`), загрузку фото/видео и кнопки `Сохранить в черновик` / `Опубликовать`.

### 3.4. Страница 4 — «Войти» (`Авторизация`, заблокирована в ЛР5) — **НЕДОСТУПНА**
Пункт меню **«Войти»** в `BottomNavBar` присутствует, но помечен `disabled` (`opacity: 0.45`), так как аутентификация, сессии и роли пользователей реализуются на следующих этапах интеграции с бэкендом (ЛР6–ЛР7). Форма входа будет содержать поля `Логин` и `Пароль` и кнопку `Войти`.

## 4. Нижняя навигационная панель (`BottomNavBar`, компоненты `Nav`, `Button`)
Фиксированная панель высотой `70px` с фоном `#2B2B2B`, содержит строго **4 пункта**:
1. **`Лента`** — **доступна**, ведёт на `/feed/1`, подсвечивается белым/активным при открытой ленте.
2. **`Добавление`** — **недоступна** (`disabled`), переход запрещён.
3. **`Плитка`** — **доступна**, ведёт на `/`, подсвечивается активным цветом на странице каталога.
4. **`Войти`** — **недоступна** (`disabled`), переход запрещён.

## 6. Инструкция по запуску и публикации в отдельный репозиторий

```bash

npm install

# 2. Запуск локального сервера разработки (http://localhost:5173)
npm run dev

# 3. Проверка типов TypeScript и production-сборка Vite
npm run build

# 4. Запуск автотестов моков, ассетов и структуры компонентов
```
